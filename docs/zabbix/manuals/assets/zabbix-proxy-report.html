1. Arquitectura de Comunicación en Modo Activo

Topología Distribuida y Resiliencia Satelital

Milicic S.A. | Monitoreo Distribuido
Modalidad de Operación
Modo Activo
Conexión saliente proactiva TCP 10051
Motor de Base de Datos
SQLite3 Embebido
Autocreación local sin mantenimiento
Buffer de Resiliencia
Híbrido (16 MB)
Retención en RAM + NVMe ante caídas
Principio Operativo: Cero Puertos Abiertos en Sucursales
El Zabbix Proxy se implementa estrictamente en Modo Activo. Esto significa que el proxy remoto es quien inicia de manera autónoma las sesiones TCP salientes hacia el Zabbix Server central (172.30.20.61:10051). No requiere interfaz web local ni reglas de port-forwarding entrantes en los firewalls FortiGate de faena.
Resguardo de Métricas durante Contingencias WAN
Si el enlace satelital Starlink sufre interrupciones por tormentas de nieve en cordillera o degradación de señal, el proxy continúa recolectando datos en memoria y disco sin pérdida. Al restaurarse el enlace hacia 172.30.20.61, el proxy vacía la cola acumulada de manera secuencial y sincronizada.

2. Guía de Instalación Paso a Paso (Ubuntu / Debian)

Despliegue del Demonio y Archivo de Configuración

Milicic S.A. | Procedimiento Técnico
1 Instalación de Paquetes Oficiales de Zabbix 7.0 LTS

Ejecutar como root en la terminal de la máquina remota (Ubuntu 26.04 / Raspberry Pi OS): 

# 1. Agregar el repositorio oficial de Zabbix 7.0 LTS
wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/zabbix-release_latest+ubuntu26.04_all.deb
dpkg -i zabbix-release_latest+ubuntu26.04_all.deb
apt update

# 2. Instalar el demonio de proxy con motor SQLite3 y fping
apt install -y zabbix-proxy-sqlite3 fping
2 Configuración del Demonio (/etc/zabbix/zabbix_proxy.conf)

Editar el archivo asignando la IP del servidor central y el nombre representativo unívoco de la localidad: 

Server=172.30.20.61
Hostname=SUCURSAL-ZAB01  # <--- Reemplazar con el nombre exacto de la localidad
LogFile=/var/log/zabbix/zabbix_proxy.log
LogFileSize=0
PidFile=/run/zabbix/zabbix_proxy.pid
SocketDir=/run/zabbix
DBName=/var/lib/zabbix/zabbix_proxy.db
DBUser=zabbix
ProxyBufferMode=hybrid
ProxyMemoryBufferSize=16M
SNMPTrapperFile=/var/log/snmptrap/snmptrap.log
Timeout=4
FpingLocation=/usr/bin/fping
Fping6Location=/usr/bin/fping6
LogSlowQueries=3000
StatsAllowedIP=127.0.0.1
Include=/etc/zabbix/zabbix_proxy.d/*.conf
Sensibilidad a Mayúsculas y Minúsculas (Case-Sensitive)
El valor del parámetro Hostname= distingue estrictamente entre mayúsculas y minúsculas. Debe ser exactamente igual al nombre con el que se registrará el proxy en la interfaz web central.
3 Permisos del Sistema e Inicialización del Servicio

Garantizar los permisos sobre los directorios operativos e iniciar el demonio systemd: 

# Crear directorios operativos para base de datos y sockets
mkdir -p /var/lib/zabbix /run/zabbix

# Aplicar permisos al usuario de servicio del sistema
chown -R zabbix:zabbix /var/lib/zabbix /run/zabbix

# Habilitar inicio automático en arranque y levantar el servicio
systemctl enable zabbix-proxy
systemctl restart zabbix-proxy
Nota de arquitectura: La base de datos SQLite3 (/var/lib/zabbix/zabbix_proxy.db) es inicializada y estructurada automáticamente por el demonio en su primera ejecución sin necesidad de ejecutar scripts SQL manuales.

3. Registro en Consola Central & Troubleshooting

Alta en Interfaz Web, Verificación y Diagnóstico

Milicic S.A. | Verificación & Calidad
4 Alta en la Consola Web del Zabbix Server Central

Ingresar al Zabbix Server (http://172.30.20.61) y completar los campos en el menú de Proxies:

Parámetro / Campo Valor Requerido Descripción & Regla Operativa
Ruta en el Menú Data collection → Proxies → Create proxy Módulo de gestión de proxies distribuidos en Sede Central.
Proxy name SUCURSAL-ZAB01 Debe coincidir exactamente con el Hostname= configurado.
Proxy mode Active El proxy inicia la sesión hacia el Server de forma saliente.
Address / Port (En blanco) En modo activo, el Server no necesita la dirección IP del proxy.
Description Proxy Monitoreo Local Faena Documentación interna y registro de ubicación geográfica.
5 Monitoreo de Logs en Vivo & Criterios de Éxito

Verificar la actividad del demonio inmediatamente tras registrar el proxy: 

tail -f /var/log/zabbix/zabbix_proxy.log
Indicador de Sincronización Exitosa
El proxy está 100% operativo cuando en la consola web la columna Last seen (age) muestra valores inferiores a 10s y en el log local se lee:
received configuration data from server at "172.30.20.61", datalen ...
Diagnóstico de Error Común en Producción: "Host Not Found"
Si en el log local se observan alertas como:
cannot send list of active checks to "192.168.x.x": host [NOMBRE] not found
Causa: Un agente de la red local está intentando enviar métricas al proxy, pero dicho equipo aún no fue dado de alta en el Zabbix Server o no tiene asignado este proxy en su campo Monitored by proxy.
Solución: Ingresar a Data collection → Hosts en el Zabbix Server y verificar que el host tenga asignado el proxy correspondiente.
